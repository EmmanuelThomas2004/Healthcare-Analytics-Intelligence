# Healthcare Analytics Intelligence

## Project Overview

Healthcare Analytics Intelligence is an end-to-end healthcare data analytics project designed to transform raw healthcare data into actionable insights across patient demographics, clinical outcomes, hospital operations, healthcare costs, and resource utilization.

The project processes five healthcare datasets containing 597,774 records and applies a complete analytics workflow from data preparation and validation to data warehousing, analytical SQL, dimensional modeling, DAX, and interactive Power BI dashboards.

## Business Problem

Healthcare organizations generate large volumes of patient, admission, diagnosis, billing, and hospital data. Without a structured analytical approach, it becomes difficult to understand patient demand, clinical outcomes, hospital utilization, healthcare expenditure, and readmission patterns.

This project addresses these challenges by integrating and analyzing healthcare data across multiple business areas.

## Objectives

- Analyze patient demographics and population patterns
- Measure admission and readmission performance
- Evaluate hospital and ward utilization
- Analyze healthcare expenditure and funding
- Monitor government subsidy and patient out-of-pocket costs
- Identify clinical diagnosis and length-of-stay patterns
- Evaluate hospital resource capacity
- Build executive-level healthcare performance dashboards

## Project Scope

The project covers:

- Data profiling and quality assessment
- Data cleaning and transformation
- Excel-based data handling
- Python and Pandas ETL
- MySQL data storage and analysis
- Snowflake data warehousing
- SQL analysis and data validation
- Power BI data modeling

- Healthcare business intelligence
