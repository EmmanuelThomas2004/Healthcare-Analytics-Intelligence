# Python Data Preparation

This section contains the Python and Pandas scripts used to profile, clean, validate, and prepare the healthcare datasets for downstream SQL, Snowflake, and Power BI analysis.

## Scripts

- `01_patients_profiling_cleaning.py` — Patient data profiling, quality checks, cleaning, and standardization
- `02_admissions_profiling_cleaning.py` — Admission data profiling, validation, transformation, and standardization
- `03_billing_profiling_cleaning.py` — Billing data quality checks, cost validation, and transformation
- `04_diagnoses_profiling_cleaning.py` — Diagnosis data profiling, validation, and standardization
- `05_hospitals_profiling_cleaning.py` — Hospital data profiling, validation, and standardization

## Technology

`Python` • `Pandas`

## Output

The scripts generate cleaned datasets used throughout the MySQL, Snowflake, and Power BI analytical pipeline.
